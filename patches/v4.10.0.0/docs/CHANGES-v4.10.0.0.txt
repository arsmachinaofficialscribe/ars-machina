FIX — Virtues & Flaws disappeared from Build (Grogs and Companions)
- Cause: for non-magi, sVF() returns two sibling sections in one part (#s-being, then #s-vf). The 4.9.10.0 keyed
  redraw, window.amWorkSet, assumed one section per part and cached the part under its first id. On the next redraw
  with that part unchanged it kept #s-being and removed #s-vf as stale. Magi have no #s-being. Data never touched.
- Fix: amWorkSet parses every top-level section of each part and tracks each by its own id (__amSrc = part key, fast
  path for an unchanged part; __amOwn = own markup key, kept when only a sibling changed). A section is removed only
  when its id is absent from the whole new render. window.__amFrag holds the current part-to-ids map only.
- CSP hashes recomputed by pack.py in both builds.
