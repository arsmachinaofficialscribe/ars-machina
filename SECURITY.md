# Security

Please report security problems privately to **security@arsmachina-scribe-and-cast.win** (also listed in the site's `/.well-known/security.txt`), not in a public issue.

Useful details: the version, the browser, and the steps or file that show the problem. A crafted character `.json` file is a welcome test case: the test suite already loads a hostile file every release, and new cases can be added to it.

The app has no server, accounts or network calls of its own; character data stays in the browser and in files the user saves.
